Immediate containment

Two externally reachable paths were closed.

Contained

Firebase Storage was public

The production bucket accepted unauthenticated reads and writes under a time-based rule through December 22, 2030. New rules now require authentication and group or chat membership, cap profile images at 10 MB, receipts at 25 MB, and chat media at 110 MB, and deny all unspecified paths.

storage.rules, production ruleset 909c18d3-def8-4e60-ba06-b3eb39324330, deployed 2026-09-01 Central time.

Contained

Group invite bypass

A signed-in user who learned a group document ID could add themselves without the invite code. The client already uses joinGroupByInviteCode, so the legacy direct-join branch was removed from Firestore authorization and deployed without rebuilding the app.

firestore.rules group update rule and functions/src/index.ts callable join path.

Security repair status

The release-blocking authorization work is complete.

Contained

UGC safety controls

Build 0.0.239 includes sensitive-content filtering, in-app message reporting, and user block or unblock controls. Reports are written through a server-only callable with authenticated rate limits and a non-public review queue.

Contained

Group administration

Role and membership changes now pass through the mutateGroupMember callable. Firestore permits a member to remove only their own membership directly and no longer accepts client-authored role changes.

Contained

Realtime messaging and calls

Message queues, calls, receipts, typing grants, and chat access are now server-authorized with participant checks, block-state enforcement, payload limits, and durable rate limits. Direct client creation of calls and other users' queues is denied.

Open risk

The new public mutation surfaces have durable per-user quotas. App Check is not enforced in build 0.0.239, and paid security-provider paths still need explicit reachability review, budget alerts, and formal risk acceptance before submission.
